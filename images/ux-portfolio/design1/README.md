# UX portfolio project images

Upload images for this project to this folder. You can add more project folders alongside `design1`, keeping each project's images together.

Use descriptive filenames, for example `research-findings.png`, `wireframes.png`, or `final-mobile-screens.webp`. To display an image on the project page, add an `<img>` element to `ux-portfolio/design1/index.html` with a path such as:

```html
<img src="/images/ux-portfolio/design1/wireframes.png" alt="Wireframes for Design 1">
```
