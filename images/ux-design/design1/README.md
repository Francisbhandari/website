# UX design project images

Upload this project's images to this folder. Create another subfolder for each additional project.

Use descriptive filenames such as `research-findings.png`, `wireframes.png`, or `final-mobile-screens.webp`. To display an image on the project page, add an `<img>` element to `ux-design/design1/index.html`, for example:

```html
<img src="/images/ux-design/design1/wireframes.png" alt="Wireframes for Design 1">
```
